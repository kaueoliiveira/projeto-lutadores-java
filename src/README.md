Projeto lutadores em java

Este projeto foi desenvolvido durante meus estudos de Java com o objetivo
de praticar a Programação Orientada a Objetos.

A aplicação simula lutas entre lutadores, permitindo o cadastro de participantes, a definição de categorias com base
no peso e a realização de combates com resultados aleatórios.

Durante o desenvolvimento foram aplicados conceitos importantes como classes e objetos,
encapsulamento, construtores, relacionamento entre classes e organização do código em múltiplas classes.

Este projeto foi criado para consolidar os fundamentos da Programação Orientada a Objetos e fortalecer minha prática com Java.
